# DAHC-UI gaps found by the multi-role portal

DAHC-UI is not changed by this work (brief: "Do not modify DAHC-UI"). Each gap below is composed inside the portal from DAHC-UI pieces and recorded here as a candidate for a later DAHC-UI release. It adds to `docs/candidate-portal/04-dahc-ui-recommendations.md`.

| Id | Gap | Needed for | Portal composition (temporary) | Proposed DAHC-UI change |
|---|---|---|---|---|
| GAP-01 | `dahc-app-header` has no projection slot or role input, so a role switch can't sit inside the header. | active-role switch (all staff; temporary until IDAM, owner 2026-11-13) | `layouts/shared/role-switch.component.ts`: a strip attached to the bottom of the header with "Working as <role>" and a `dahc-menu` "Switch role". Shown only for 2+ roles. | Add an `[app-header-actions]` slot or a `roles` / `activeRole` input with a `roleChange` output. Low priority, since the switch is temporary. |
| GAP-02 | `dahc-table` pages on the client, and `dahc-pagination` needs a `total`. The contract uses cursors (`limit` / `nextCursor`) with no totals. | every staff list | `shared/cursor-list/`: `CursorList<T>` signal state plus `dahc-load-more` (a "Load more" button with a live count announcement), next to a `dahc-table` with server sort. | A cursor mode on `dahc-pagination` (previous/next only) or a `dahc-load-more` component. |
| GAP-03 | No chart components. | US-2.1.4 monitoring (stacked bar, pies) | `shared/charts/` (built in Phase 5): a stacked bar chart (flexbox, RTL-aware) and an SVG donut chart. Segments are focusable buttons with accessible names, there is a legend, and a "Show as table" toggle opens a `dahc-table` alternative. Tokens only, no animation. | `dahc-bar-chart` and `dahc-pie-chart` with a built-in table fallback. |
| GAP-04 | `dahc-result` has no 403 / 404 variants. | unauthorised, not-found, no-area pages | `dahc-result` with `status="warning"` / `"info"` and portal headings. | `status="403" / "404"` variants. |
| GAP-05 | `dahc-app-header` navigation is flat (`DahcNavLink[]`). | staff areas with several sections | Not needed yet. Each role sees one to three header items (`layouts/staff-layout/staff-nav.ts`, filtered by permission). If a role's menu grows, use `dahc-sider` + `dahc-nav-menu mode="vertical"` inside `dahc-layout`. | Nested items in `dahc-app-header`, or a documented header + sider shell pattern. |
| GAP-06 | No attachment viewer with rotate and zoom (`dahc-image-preview` covers images only, not PDFs). | US-2.3.1, US-3.3.1 | `shared/attachment-viewer/`: images through `dahc-image-preview`; PDFs downloaded or opened in a new tab through a blob URL. | A document viewer component (needs a CSP decision for PDF rendering). |
| GAP-07 | `dahc-file-upload` has no "justification first" step. | US-2.3.6, US-3.2.3 | A dialog with a `dahc-form-field` textarea, then `dahc-file-upload`. | None: the composition is fine. Recorded for completeness. |
| GAP-08 | ~~No character counter on `dahc-form-field`~~. **Withdrawn (Phase 3):** `dahc-form-field` already has `showCount`. | – | Use `showCount`. | None. |
| GAP-09 | `dahc-tag` has only `md` and `lg` sizes. | inline markers (Overdue, From ICP, Flagged) | `md` tags. | A `sm` size. |
| GAP-10 | `dahc-modal` has a built-in header button named "Close", so a footer button with the same name is ambiguous for screen readers. | result dialogs (bulk results) | Footer button named "Done". | Document this, or allow a custom header close label. |
| GAP-11 | `dahc-tabs` cannot render panels created with `@for`: the required panel `name` is read before it is set (NG0950), which breaks the page. | application review sections (US-2.3.1) | Sections are stacked panels, each under its own heading. | Support dynamic `dahc-tab-panel` children. |
| GAP-12 | `dahc-alert` renders its heading as a `<p>`, so alert titles are not in the heading outline. | all alerts with headings | Accepted for now. | Add a `headingLevel` input. |
| GAP-13 | `dahc-checkbox` only works with Angular forms: `value` is protected and there is no `valueChange` output. | ICP refresh field selection (US-2.5.3) | One `FormControl` per checkbox. | A `checked` model or a `valueChange` output. |
| GAP-14 | No warning or alert icon in the icon set. | ICP differences, overdue items | The `information` icon plus text. | Add `warning` / `alert` icons. |
| GAP-15 | `dahc-select` has no clean "All" option. | list filters (screening, reinstatements) | The empty placeholder acts as "All". | An optional "all" item, or a clearable select. |
| GAP-16 | Form controls cannot take an external `aria-describedby`. | candidate corrections (US-2.3.4): an officer note tied to its field | The note is shown visibly above the section. | An `ariaDescribedBy` input on form controls. |
| GAP-17 | A `dahc-table` with `scrollX` inside a CSS grid widens the page at 320 px unless the grid column is `minmax(0, 1fr)`. | every staff list | `grid-template-columns: minmax(0, 1fr)` on page grids. | Document it, or set `min-inline-size: 0` on the host. |
| GAP-18 | `dahc-accordion-item` takes a text heading only, so a tag or status cannot sit in the heading. | portfolio scoring question cards (US-3.3.3) | The state goes into the heading text, for example "– needs your decision". | A heading slot or a `status` input. |
| GAP-19 | No left arrow icon. | back links | `chevron-left`. | Add `arrow-left` / `arrow-right` icons (mirrored in RTL). |
