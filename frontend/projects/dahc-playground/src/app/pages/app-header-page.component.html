Signed out, without a language link

  • The skip link is the first focusable element; it appears on focus and moves focus to the element named by mainContentId.
  • The header is a banner landmark; use one per page.
  • The language link sets hreflang and lang, so its text is pronounced in its own language.
  • Sign out is a native button that emits signOut; the application performs the sign-out.
  • The navigation is a labelled nav landmark; the current page has aria-current="page" and a 4px underline.
  • Below 1024 pixels a Menu button opens the navigation, language, theme and sign-out in a modal drawer.
  • The notifications button is named "Notifications"; the badge's count is announced with its label.
