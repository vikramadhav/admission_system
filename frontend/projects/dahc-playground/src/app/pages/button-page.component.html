  • Use a native button for actions and a link for navigation; both keep their own role and keyboard support (Enter, and Space for buttons).
  • Disabled buttons get the disabled attribute; disabled links get aria-disabled="true" and leave the tab order.
  • While loading the button is busy (aria-busy) and announces the loading label; clicks are ignored.
  • The focus ring uses the focus-ring token and is visible in both themes and in forced-colours mode.
  • Minimum target size is 44 by 44 pixels.
