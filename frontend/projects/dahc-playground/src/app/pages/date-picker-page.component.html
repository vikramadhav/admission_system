Calendar value: {{ calendarValue() }}

  • The calendar button names the popup ("Choose date") and reports aria-expanded; Alt+ArrowDown opens it from the field.
  • In the calendar: arrows move by day and week, Page Up / Page Down by month (Shift for a year), Home / End to the week's start and end, Enter or Space chooses, Escape closes and returns focus.
  • Each day button is named with the full date; today has aria-current="date"; days outside min / max are disabled.
  • Arrow keys follow the reading direction in right-to-left.
  • An unreadable date, or one outside min / max, gives a visible error and a form validation error.
