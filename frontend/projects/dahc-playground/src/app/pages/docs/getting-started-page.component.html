Getting started

DAHC UI is a library project in the frontend Angular workspace. Applications in the same workspace use it directly from source.

1. Add the styles and assets

The stylesheet emits every design token as a CSS custom property and adds the Dubai font, base styles and type roles. Icons and logos are SVG files that the build copies next to your app. 

{{ angularJson }}

Point TypeScript at the library sources (already set in this workspace):

{{ tsconfig }}

2. Use a component

Every component is standalone: import it where you use it.

{{ component }}

3. Forms

Form controls implement ControlValueAccessor, so they work with Reactive and template-driven forms. Text inputs use the native element with the dahcInput directive inside dahc-form-field, which adds the label, hint, error and required marker. 

{{ forms }}

4. Optional providers

{{ providers }}

Place one <dahc-toast-region /> (and <dahc-message-region /> and <dahc-notification-region /> if you use them) in your root layout so the services have somewhere to show messages.
