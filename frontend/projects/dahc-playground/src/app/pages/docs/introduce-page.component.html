DAHC UI

DAHC UI is the Angular component library of the Dubai Health Standard UI. It turns the Dubai Health design system in Figma into accessible, right-to-left ready components for Dubai Health web applications such as the GME admission portal.

Features

  • Dubai Health designBuilt from the Dubai Health Standard UI and its tokens: colour, typography (Dubai font), spacing, radius, shadow and motion.
  • Modern AngularStandalone components, signal inputs and models, OnPush change detection, and Reactive Forms through ControlValueAccessor.
  • AccessibleWCAG 2.2 AA: WAI-ARIA keyboard patterns, visible focus, live announcements, reduced motion and forced colours. Every component is tested with axe.
  • Arabic and right-to-leftLogical CSS properties throughout, mirrored icons, and every built-in text translatable with Angular i18n.
  • Light and dark themesSemantic colour roles switch with one attribute; components never use raw colours.
  • No third-party UINative HTML, CSS and Angular only: no CSS framework, no Angular CDK, no UI vendor dependency.

Supported environment

  • Angular 22 with standalone components and zoneless or zone-based change detection.
  • Current versions of Chrome, Edge, Firefox and Safari, on desktop and mobile.
  • Screen readers: NVDA and JAWS on Windows, VoiceOver on macOS and iOS, TalkBack on Android.

Design resources

The Dubai Health Standard UI Figma file is the source of truth for tokens and components; application screens, such as the GME portal, have their own Figma files built from it. Values that Figma does not define are marked "DAHC proposal" or "A11y fix" in the library source and in the design-system documents (frontend/docs/design-system).
