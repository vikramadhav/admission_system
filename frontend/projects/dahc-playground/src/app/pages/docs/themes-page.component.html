Themes and languages

DAHC UI supports a light and a dark theme, Arabic and other right-to-left languages, and translation of every built-in text.

Light and dark theme

Components use semantic colour roles only (for example --dahc-color-surface), so a theme is one attribute on the root element: data-theme="light" or data-theme="dark". The theme service remembers the user's choice and otherwise follows the system setting. 

{{ theme }}

Right-to-left

Layouts use logical CSS properties and directional icons mirror automatically, so setting dir="rtl" on the document (or on a dahc-config-provider for one part of a page) is all that is needed. Use the Right-to-left switch in the header to try any page. 

{{ direction }}

Translations

Built-in texts (loading labels, close buttons, pagination, calendar names and so on) use Angular $localize with ids that start with dahcUi., and each one is also an input you can set directly.
