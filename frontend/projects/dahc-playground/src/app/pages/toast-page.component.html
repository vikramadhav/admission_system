Toasts stack at the bottom end of the screen, newest last; full width on small screens.

  • The list is a permanent polite live region, so new toasts are announced; errors use role="alert".
  • The timer pauses while the pointer or keyboard focus is on a toast (WCAG 2.2.1); every toast can be dismissed.
  • Use toasts for confirmations only; put anything the user must act on in the page (alert) or a dialog.
